1. INTRODUCTION                                                *cueline-intro*

cueline links an `.srt` or `.ass`/`.ssa` buffer to the IINA media player on
macOS. The line being spoken is highlighted and kept in view as playback
moves, and IINA shows it as a caption over the video, including edits you
haven't saved yet.

In `.ass`/`.ssa` files (Advanced SubStation Alpha) each `Dialogue:` line is
one cue; `Comment:` lines are skipped. ASS lines often overlap, e.g. a sign
on screen while people talk. Every line playing at the moment is highlighted,
and following tracks the one that started most recently.

IINA renders `.ass`/`.ssa` buffers itself, with libass, so styles, positioning
and animations look as they will in the finished file. cueline writes the
buffer, unsaved edits included, to a temp file and has IINA load it as a
subtitle track, reloading it about 150 ms after you stop typing. While it's
loaded that track is selected and subtitles are switched on; when you detach,
disconnect or switch to an `.srt` buffer it's removed and your own subtitle
track and visibility come back. The temp file is deleted then too. This is
why the IINA plugin asks for file system access when installed.

It needs the companion IINA plugin, installed from IINA → Settings → Plugins →
Install from GitHub… with `Bajortski/cueline`. Restart IINA after installing.

2. SETUP                                                       *cueline-setup*

With lazy.nvim: >lua
    {
      "Bajortski/cueline",
      ft = { "srt", "ssa" },
      cmd = { "CuelineConnect", "CuelineOpen" },
      opts = {},
    }
<
Otherwise: >lua
    require("cueline").setup({})
<
Run |:checkhealth| `cueline` to check the setup.

3. USAGE                                                       *cueline-usage*

1. Open an `.srt`, `.ass` or `.ssa` file. cueline turns on for it
   automatically.
2. Run |:CuelineOpen| to open the matching media in IINA and connect, or open
   the media in IINA yourself and run |:CuelineConnect|.
3. Play. The playing line is highlighted and kept centred.
4. Edit. The caption in IINA follows every keystroke.

Following pauses for |cueline-follow_idle_ms| after you move the cursor or
type, and never happens in insert mode. While paused, moving the cursor
previews the line under it in the player.

For `.srt` files the caption is drawn by cueline. It renders SRT formatting
tags: `<b>`, `<i>`, `<u>`, `<s>` and `<font color="...">`. An ASS `{\anN}` tag
moves it, e.g. `{\an8}` to the top centre; other `{\...}` blocks are hidden.
Anything else in angle brackets is shown as written. `.ass`/`.ssa` files are
rendered by IINA (see |cueline-intro|), which always shows what's at the
playback position, so moving the cursor while paused doesn't preview them.

IINA opens audio-only files in music mode, which hides the caption. Use
Video → Exit Music Mode in IINA. Everything else works regardless.

4. COMMANDS                                                 *cueline-commands*

:CuelineOpen [path]                                             *:CuelineOpen*
    Open the media for the current transcript in IINA, and connect. Without
    [path], looks for a file with the same name and a known media extension
    in each of |cueline-media_dirs|, relative to the transcript.

:CuelineConnect [port]                                       *:CuelineConnect*
    Connect to IINA, retrying until it's available (see |cueline-reconnect|).

:CuelineDisconnect                                        *:CuelineDisconnect*
    Disconnect and stop retrying.

:CuelineSeek                                                    *:CuelineSeek*
    Jump the player to the start of the line under the cursor.

:CuelineReplay                                                *:CuelineReplay*
    Like |:CuelineSeek|, and start playing.

:CuelinePause                                                  *:CuelinePause*
    Toggle play/pause.

:CuelineNudge [secs]                                          *:CuelineNudge*
    Skip forward by [secs], or back if negative. Defaults to
    |cueline-nudge|.

:CuelineSpeed {x}                                              *:CuelineSpeed*
    Set the playback speed.

:CuelineFollow [on|off]                                       *:CuelineFollow*
    Turn following on or off. Without an argument, toggle it.

:CuelineAdjust {start|end} {secs}                             *:CuelineAdjust*
    Shift the start or end time of the line under the cursor by {secs}.

:CuelineStamp {start|end}                                      *:CuelineStamp*
    Set the start or end time of the line under the cursor to the current
    playback position.

:CuelineAttach                                                *:CuelineAttach*
:CuelineDetach                                                *:CuelineDetach*
    Turn cueline on or off for the current buffer.

:CuelineExport [output]                                       *:CuelineExport*
    Convert the buffer to YouTube's styled timed-text format (`.ytt`), using
    YTSubConverter. See |cueline-export|.

:CuelineStatus                                                *:CuelineStatus*
    Show the connection and player state.

==============================================================================
5. KEYS                                                         *cueline-keys*

Set in subtitle buffers only, in normal mode. In `.ass`/`.ssa` files they act
on the `Dialogue:` line under the cursor; timing changes rewrite only its
Start and End fields, rounded to hundredths of a second.

    <CR>               Jump the player to the line under the cursor
    <localleader>r     Play the line under the cursor from its start
    <localleader>p     Play / pause
    <localleader>f     Turn following on or off
    <localleader>h     Skip back |cueline-nudge| seconds
    <localleader>l     Skip forward |cueline-nudge| seconds
    <localleader>[     Move the line's start earlier by |cueline-adjust|
    <localleader>]     Move the line's start later
    <localleader>{     Move the line's end earlier
    <localleader>}     Move the line's end later
    <localleader>S     Set the line's start to the playback position
    <localleader>E     Set the line's end to the playback position

Change them with |cueline-keymaps|.

6. OPTIONS                                                   *cueline-options*

Pass these to `setup()`. Defaults are shown.

                                                                *cueline-host*
host = "127.0.0.1"
    Where IINA is running.

                                                                *cueline-port*
port = 10427
    Must match the port in IINA → Settings → Plugins → cueline.

                                                           *cueline-reconnect*
reconnect = true
    Keep retrying after |:CuelineConnect| until IINA answers, and reconnect if
    the connection drops.

                                                         *cueline-auto_attach*
auto_attach = true
    Turn cueline on for every buffer with filetype `srt` or `ssa` (Neovim's
    filetype for `.ass` and `.ssa` files).

                                                        *cueline-auto_connect*
auto_connect = false
    Connect as soon as the first subtitle buffer is opened.

                                                              *cueline-follow*
follow = true
    Move the cursor along with playback.

                                                      *cueline-follow_idle_ms*
follow_idle_ms = 2500
    Don't follow within this many milliseconds of your own cursor movement
    or edits.

                                                       *cueline-follow_center*
follow_center = true
    Keep the playing line centred in the window. When false, the view only
    scrolls once the playing line goes off-screen.

                                                   *cueline-preview_on_cursor*
preview_on_cursor = true
    While paused, show the line under the cursor as the caption.

                                                           *cueline-hide_subs*
hide_subs = true
    Hide IINA's own subtitle track while cueline's caption is showing.
    Doesn't apply to `.ass`/`.ssa` buffers, whose live track replaces it.

                                                           *cueline-lookahead*
lookahead = 3
    How many upcoming lines to send ahead, so the caption changes on time.

                                                               *cueline-nudge*
nudge = 2
    Seconds skipped by the nudge keys and |:CuelineNudge|.

                                                              *cueline-adjust*
adjust = 0.1
    Seconds moved by the timing keys.

                                                      *cueline-seek_on_adjust*
seek_on_adjust = true
    After moving a line's start, jump the player there so you can hear it.

                                                          *cueline-media_exts*
media_exts = { "m4a", "mp3", "wav", "flac", "ogg", "opus", "aac",
               "mp4", "mkv", "mov", "webm", "m4v" }
    Extensions |:CuelineOpen| looks for.

                                                          *cueline-media_dirs*
media_dirs = { ".", "../audio", "../video", "../media" }
    Folders |:CuelineOpen| searches, relative to the transcript.

                                                      *cueline-ytsubconverter*
ytsubconverter = nil
    Path to the YTSubConverter executable used by |:CuelineExport|. When
    unset, cueline looks for `YTSubConverter` on your `PATH`, then for
    `YTSubConverter.app` in `/Applications` and `~/Applications`. For an app
    elsewhere, give the binary inside it: >lua
      ytsubconverter = "~/bin/YTSubConverter.app/Contents/MacOS/YTSubConverter"
<
                                                             *cueline-keymaps*
keymaps = { seek = "<CR>", replay = "<localleader>r", ... }
    Keys by action name: `seek`, `replay`, `toggle_pause`, `follow`, `back`,
    `forward`, `start_earlier`, `start_later`, `end_earlier`, `end_later`,
    `stamp_start`, `stamp_end`. Set one to `false` to disable it, or set
    `keymaps = false` to disable them all.

7. HIGHLIGHTS                                             *cueline-highlights*

CuelineActive                                          *hl-CuelineActive*
    The playing line, or every playing line when they overlap. Links to
    |hl-DiffChange| by default.

CuelineSign                                              *hl-CuelineSign*
    The `▶` sign next to the playing line. Links to `DiagnosticInfo` by
    default.

8. LUA API                                                       *cueline-api*

require("cueline").setup({opts})                             *cueline.setup()*
    Apply options. See |cueline-options|.

require("cueline").statusline()                         *cueline.statusline()*
    Returns the playback position for a statusline, e.g. `▶ 01:02:03`
    (`⏸` when paused). While connecting it returns `cue:…`, and when not
    connected an empty string.

The WebSocket protocol between the two plugins is documented in
`docs/protocol.md` in the repository.

==============================================================================
9. TROUBLESHOOTING                                   *cueline-troubleshooting*

|:CuelineConnect| keeps retrying ~
    IINA isn't running, or was already running when the plugin was installed.
    Restart IINA, and check the plugin is enabled and the ports match.

No caption in IINA ~
    IINA is in music mode. Use Video → Exit Music Mode.

|:CuelineOpen| can't find the media ~
    Pass the path, or add your folder to |cueline-media_dirs|.

The cursor doesn't follow ~
    See |cueline-follow_idle_ms|, and check |:CuelineStatus|.

==============================================================================
10. EXPORTING FOR YOUTUBE                                     *cueline-export*

|:CuelineExport| converts an `.ass`, `.ssa` or `.srt` buffer to YouTube's
styled timed-text format (`.ytt`, also called srv3), which keeps colours,
positioning and karaoke that a plain `.srt` upload loses. Upload the result
to YouTube Studio as a subtitle file.

It converts what's in the buffer, unsaved edits included, and runs in the
background. Without an argument, the output goes next to the buffer's file
with a `.ytt` extension. An [output] path is relative to the current
directory, and its extension picks the format: `.ytt`, `.srv3`, `.ass`,
`.srt` or `.sbv`. If the conversion fails, an existing output file is left
as it was.

Install YTSubConverter ~
    Download the macOS build from
    https://github.com/arcusmaximus/YTSubConverter/releases and move
    `YTSubConverter.app` to `/Applications`, or point |cueline-ytsubconverter|
    at it. |:checkhealth| `cueline` reports whether it's found.

    The app isn't notarized, so macOS may refuse to run a copy downloaded in a
    browser. Clear the quarantine flag: >sh
      xattr -d com.apple.quarantine /Applications/YTSubConverter.app
<
What survives ~
    From styles: font, size, bold, italic, underline, colours, alignment,
    and outline or shadow (on or off, not its width).

    Override tags: `\b` `\i` `\u` `\fn` `\fs` `\c` `\1c`-`\4c` `\1a`-`\4a`
    `\alpha` `\pos` `\an` `\k` `\r` `\fad` `\fade` `\move`, and `\t` for
    colour, alpha and size only.

    Not supported: `\fscx` `\fscy` `\frz` `\clip` `\blur`, `\bord` and
    `\shad` widths, and `\p` drawings.

    YouTube's mobile apps ignore background customisation, and the Android
    app ignores font size.

    `docs/ass-cheatsheet.md` in the plugin's repository lists every tag and
    style field with what survives export.
